# Frontend Development
- ## HTML Example
    ```html
    <!DOCTYPE html>
    <html>
    <head>
    <title>Page Title</title>
    </head>
    <body>

    <h1>My First Heading</h1>
    <p>My first paragraph.</p>

    </body>
    </html>
    ```

- ## HTML Tag Example
  ```html
    <!DOCTYPE html>
    <html>
    <head>
    <!-- <title> tag -->
    <title>HTML Tags Example</title>
    </head>
    <body>

    <!-- <h1> and <h6> tag -->
    <h1>Main Heading of the Page</h1>
    <h2>Subheading - Level 2</h2>
    <h3>Subheading - Level 3</h3>
    <h4>Subheading - Level 4</h4>
    <h5>Subheading - Level 5</h5>
    <h6>Subheading - Level 6</h6>

    <!-- <p> tag -->
    <p>HTML is used to build the structure of web pages easily.</p>

    <!-- <a> tag -->
    <a href="https://nitgoa.ac.in/">NIT Goa</a><br>

    <!-- <br> tag -->
    <br>Here is a new line after the break.<br>

    <!-- <img> tag -->
    <img src="img_Program.jpg" alt="Sample Placeholder Image">

    <!-- <div> tag -->
    <div>
        <p>This paragraph is grouped inside a div section.</p>
    </div>

    <!-- <form> tag -->
    <form>
        <label for="name">Your Name:</label>
        <input type="text" id="name" name="name">
    </form>

    </body>
    </html>
  ```
